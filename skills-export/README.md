# مهارات فيديوهات «إيه الحكاية؟»

| الملف | الطريقة |
|---|---|
| `animation.zip` | الانيميشن (الكارتون)، الطريقة الأساسية لكل فيديو |
| `diagram.zip` | الرسم الهندسي (زي فيديو الأشعة) |
| `law.zip` | أسلوب «لو» (زي فيديو الملجأ النووي) |
| `humanizer.zip` | تنضيف السكريبت والعناوين من أسلوب الذكاء الاصطناعي |

كل ملف فيه المهارة نفسها ومعاها `kit/`: أدوات الرندر والصوت والمؤثرات وفحص الجودة، والفيديوهات المرجعية اللي بنبدأ منها.

## تضيفها لحساب Claude تاني

- **claude.ai:** Settings ← Capabilities ← Skills ← Upload skill، وارفع كل zip لوحده. ارفع `animation.zip` و`humanizer.zip` دايمًا، لأن الرسم الهندسي و«لو» بيعتمدوا عليهم.
- **Claude Code:** فك الملفات جوه `~/.claude/skills/`.
- أو افتح الريبو ده نفسه في Claude Code: المهارات موجودة في `.claude/skills/` وبتشتغل لوحدها.

الرندر محتاج بيئة فيها Node وPlaywright وffmpeg وPython (زي Claude Code على الويب)، والصوت محتاج مفتاح Gemini API.

## لما تعدّل مهارة

عدّل `.claude/skills/<name>/SKILL.md`، وبعدين من جذر الريبو شغّل:

```
bash skills-export/build.sh
```
