# طب إزاي؟


> **ابدأ من [`PROJECTS.md`](PROJECTS.md):** فيه كل المشاريع والأساليب وخط الإنتاج في مكان واحد.
صفحة المحتوى والسيستم ديزاين لفيديوهات «طب إزاي؟»، اللي بتشرح إزاي الحاجات المعقدة بتشتغل.

- `index.html`: صفحة المحتوى. فيها الحلقة الجديدة بتتشغّل لوحدها، وفلاتر التصنيفات، ومكتبة الحلقات، وخانة اقتراح سؤال.
- `design-system/`: السيستم ديزاين نفسه.
  - `README.md`: الدليل، وفيه الكلام والنبرة والألوان ومعانيها والخط والرسم والحركة.
  - `tokens.json` و`tokens.css`: التوكنز (الثيم الفاتح «Paper» والغامق «Night desk»).
  - `components/bundle.css`: الكومبوننتس وقيم الحركة.
  - `components/bundle.js`: محرك الحركة `window.TebEzay`.
  - `components/<Name>/`: معاينة شغالة وإرشادات لكل كومبوننت.

لو عايز تفتح الصفحة على جهازك: `npx serve .` وبعدين افتح `index.html`.
