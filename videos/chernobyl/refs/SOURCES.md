Commons blocked its search API for this session (HTTP 429) and other guessed file names did not exist, so these are drawn
from documented features without a photo: the AZ-5 panel (a red push button under a white label «АЗ-5»), the firemen's
helmets with a crest, the red fire trucks, the yellow evacuation buses, the Soviet radio and TV set, the Mi-8 helicopter,
the New Safe Confinement arch (2016), and Przewalski's horses and wolves in the zone.
