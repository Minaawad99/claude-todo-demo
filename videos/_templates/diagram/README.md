# تمبلت «الرسم الهندسي» المشترك

ده التمبلت اللي أي حلقة «إيه الحكاية؟» بأسلوب الرسم الهندسي بتبدأ منه. اتعمل من دليل الأسلوب
`videos/_reference/tabizzay/STYLE.md`، اللي طالع من تحليل 20 فيديو مرجع. وفيه حلقة تجريبية شغالة هي `videos/diagram-demo/`:
بتوري كل مرحلة وكل أداة، فانسخ منها.

## الملفات

| الملف | وظيفته |
|---|---|
| `template.html` | الصفحة: الكانفاس 360×640 (بيطلع 1080×1920 بـ `SCALE=3`)، والكارت، واللوحة، والخط الفاصل، والكلام المكتوب، وكارت البداية، والفاصل، وكارت الملخص، وكارت الدعوة |
| `engine.js` | المحرك المشترك: بيحسب كل مرحلة من `TIMING`، وبيشغّل الكلام المكتوب كلمة كلمة وحتة حتة، وبيرسم حلقة الساعة وإطار الكروت |
| `_helpers.js` | أدوات الرسم والحركة اللي الحلقة بتستعملها في `shots.js` |
| `build.py` | بيتنسخ جنب حلقتك، وبيطلّع `scenes.js` و`index.html` |

## حلقة جديدة في 5 خطوات

```bash
mkdir -p videos/<الحلقة>/diagram
cp videos/_templates/diagram/build.py videos/<الحلقة>/diagram/
cp videos/diagram-demo/diagram/{episode.py,shots.js} videos/<الحلقة>/diagram/   # وبعدين امسح محتواهم واكتب حلقتك
```

1. **`script.txt` و`timing.js`** في فولدر الحلقة. بيتعملوا بنفس طريقة الـ PLAYBOOK: الصوت، وبعدين `align_asr.py`، وبعدين `map_timing.py`.
2. **`episode.py`** فيه:
   - `CFG`: العنوان، والتصنيف، وكارت الملخص، والعلامة المائية لو عايزها.
   - `K`: الكلمات المهمة وألوانها:
     - `o` برتقالي؛
     - `b` أزرق؛
     - `g` زيتوني؛
     - `u` خط تحتها؛
     - `gr` رمادي.
   - `CAPTEXT`: لو الكلام المكتوب مختلف عن المنطوق، زي الأرقام بالأرقام.
   - `SPLIT`: لو عايز تقسّم الجملة بنفسك.
3. **`shots.js`**: لكل لقطة `shot(بداية, كاميرا, رسمة, {tr})`. والحاجات اللي بتفضل ثابتة فوق اللوحة بـ `hud(من, لحد, رسمة)`. وكمان `SCENE.intro` و`SCENE.bumper` و`SCENE.outro`.
4. **`python3 build.py`** بيطبعلك كل مرحلة بدأت عند أنهي سطر، وأي كلمة مهمة مش لاقيها.
5. **المراجعة:** `node tools/strip.js <index.html> out.png 6 <أوقات…>` بيطلّعلك فريمات كتير في صورة واحدة. وبعدين `node render.js <index.html> voice.wav out.mp4`.

## المراحل (بتتحسب لوحدها من السكريبت)

| المرحلة | السطور | بيحصل فيها إيه |
|---|---|---|
| كارت البداية | من 0 لحد قبل الوعد | الإطار المزدوج وعلامات القص بيترسموا، والتصنيف بيظهر، والخطّاف بيظهر **كلمة كلمة مع الصوت**. كل سطر من الخطّاف بيبدّل اللي قبله، والرسمة من `SCENE.intro` |
| الفاصل | السطر اللي فيه «إيه الحكاية؟ … هشرح…» | دايرة جواها أيقونة الموضوع من `SCENE.bumper`، وحلقة برتقالي بتتملي زي ساعة إيقاف، وتحتها «إيه الحكاية؟» و«هشرحهالك في دقيقة.» |
| اللوحة | لحد قبل الملخص | اللقطات وتحتها الكلام المكتوب. الكلام **بيتقسم لحتت حوالي 5 كلمات**، عند ، و… و. و؟، وكل حتة بتظهر في وقتها جوه السطر |
| كارت الملخص | من «ودي كانت…» | السؤال، والرسمة المرقّمة، والشرح، والرقم الكبير، و3 نقط، و«معلومة زيادة». كل جزء بيظهر بعد اللي قبله |
| كارت الدعوة | سطر «قولولنا…» | «قولولنا… عايزين تعرفوا حكاية ___؟» بمؤشر بيرمش، مكان النقط |

لو المراحل اتحسبت غلط، تقدر تحدد أرقام السطور بنفسك في `CFG`: `intro_lines` و`promise` و`summary` و`cta`.

## أدوات الحركة (`_helpers.js`)

| الأداة | استعمالها |
|---|---|
| `shot(n أو [n, حتة], cam, draw, {tr})` | لقطة بتبدأ مع سطر أو مع حتة من السطر. `tr` نوعه: `"fade"`، أو `"in"` (الكاميرا تدخل في اللقطة القديمة)، أو `"out"` (تبدأ قريب وتبعد) |
| `push(x,y,z1,z2)`، `pan(x1,y1,x2,y2,z)` | حركة الكاميرا جوه اللقطة. وفوقها فيه حركة خفيفة طول الوقت، فالكاميرا عمرها ما تقف |
| `at(u, من, مدة)` | قيمة من 0 لـ 1 بتمشي مع الوقت، بتستعملها في كل حركة |
| `appear(k, …)` | الحاجة تظهر رمادي باهت الأول وبعدين تاخد لونها |
| `dim(k, …)` | الحاجة تبهت، عشان اللي بنتكلم عنه يبان أكتر |
| `sweep(x,y,w,h,k,dir, …)` | اللون يمشي على طول الجزء |
| `draw(d, k, …)` | خط بيترسم قدام عينك |
| `label(…)` | عنوان بخط موصّل: النقطة، وبعدين الخط يترسم، وبعدين الاسم |
| `cross`، `check` | ✗ و✓ بيتكتبوا |
| `count(to, k)`، `bigNum(…)`، `numBox(…)` | أرقام بتعدّ، ورقم Serif كبير وتحته وحدته، ورقم في مربع |
| `iconBox(…)` | مربع صغير فيه أيقونة التشبيه، في الركن اللي فوق |
| `inset(…)` | دايرة تكبير على تفصيلة |
| `arrow`، `wave`، `callout` | أسهم، وموجات ماشية، وأرقام في دواير ①② |
| `hud(من, لحد, draw)` | حاجات ثابتة فوق اللوحة طول جزء من الحلقة: قاعدة، أو حالة، أو قايمة ✓ |

الألوان كلها مقاسة من الفيديوهات المرجع: `INK` و`PAPER` و`ORANGE` و`BLUE` و`OLIVE` و`SKIN` و`BEIGE` و`GREY` و`KHAKI` و`TAN`.

**النسخة القديمة:** التمبلت الأولاني اتنقل لـ `videos/_templates/diagram-v1/`، لأن حلقة `xray-diagram` لسه مبنية عليه.
