# مكتبة المرجع: 20 فيديو «ابنيها بنفسك»

دي الفيديوهات اللي أسلوب **«ابنيها بنفسك»** اتبنى عليها. موجودة هنا عشان أي سيشن جديدة ترجع لها من غير ما الفيديوهات تترفع تاني.
بناخد منها الطريقة بس (بناء القصة، والصوت، والإيقاع، والبناء اللي بيكبر)، ومش بننسخ رسمة ولا سكريبت.

| الملف | فيه إيه |
|---|---|
| `STYLE.md` | الدليل بالأرقام: السكريبت، والصوت، والصورة، والكلام على الشاشة، والخاتمة |
| `notes/vNN.md` | تحليل كل فيديو: اللقطات بالثانية، والكاميرا، والبطاقات، والخاتمة |
| `transcripts.txt` | كلام الـ 20 فيديو بتوقيته (بالسعودي، زي الأصل) |
| `sheets/vNN.jpg` | لقطة كل 2.5 ثانية، والوقت مكتوب فوق |
| `videos/vNN.mp4` | الفيديو بحجم صغير (360 عرض، 15 فريم، بالصوت) |
| `map.txt` | رقم كل فيديو قصاد اسم الملف اللي اترفع |

```bash
ffmpeg -ss 12 -t 3 -i videos/v10.mp4 -vf "fps=4,scale=180:-2,tile=6x2" -frames:v 1 strip.jpg   # 12 لقطة في 3 ثواني
```
