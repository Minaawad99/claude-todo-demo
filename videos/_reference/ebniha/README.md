# مكتبة المرجع: 20 فيديو «ابنيها بنفسك»

الفيديوهات اللي الأسلوب ده هيتبني عليها. موجودة هنا عشان أي سيشن جديدة تقدر ترجع لها من غير ما الفيديوهات تترفع تاني.
بنتعلم منها الطريقة بس (بناء القصة، والصوت، والإيقاع، وشكل البناء وهو بيكبر)، ومش بننسخ رسمة ولا سكريبت.

| الملف | فيه إيه |
|---|---|
| `sheets/vNN.jpg` | لقطة كل 2.5 ثانية، والوقت مكتوب فوق على الشمال |
| `videos/vNN.mp4` | الفيديو بحجم صغير (360 عرض، 15 فريم، بالصوت) |
| `frames/` | لقطات متتالية للحركة |
| `map.txt` | رقم كل فيديو قصاد اسم الملف اللي اترفع |

التحليل الكامل (`notes/` و`transcripts.txt` و`STYLE.md`) هيتضاف لما يخلص.
