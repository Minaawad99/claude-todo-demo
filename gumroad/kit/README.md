# حزمة فيديوهات الأنيميشن بالذكاء الاصطناعي

## محتويات الحزمة
- `eh-elhekaya-script/`: مهارة (Skill) بتكتب سكريبت فيديو الشرح والـstoryboard والعناوين بأسلوب «إيه الحكاية؟».
- `eh-elhekaya-animation/`: مهارة بترسم الفيديو وتطلّعه. Claude Code بيرسم مشهد متحرك لكل سطر، ويركّب صوتك والترجمة كلمة بكلمة والمؤثرات، ويطلع فيديو MP4 عمودي 1080×1920 جاهز للنشر.
  - `engine/`: المحرك (الرسم والتوقيت والصوت والإخراج)، و`engine/API.md` فيه كل دوال الرسم.
  - `example/`: فيديو مثال كامل («ليه السما لونها أزرق؟»): السكريبت والإعدادات والمشاهد والمؤثرات. ناقصه صوتك بس.
- `prompts/`: برومبتات جاهزة للنسخ لو مش هتستخدم المهارات:
  - `01-script.md`: كتابة السكريبت.
  - `02-storyboard.md`: تقسيم السكريبت لمشاهد.
  - `03-voice-style.txt`: ستايل الصوت لـGoogle AI Studio.
  - `04-titles-cover.md`: العناوين وبرومبت الـCover.
- `examples/`: سكريبت حقيقي كامل ومثال لـstoryboard.

## الحاجات اللي هتحتاجها
- **Claude Code**: من تطبيق Claude على الموبايل، أو من الكمبيوتر. محتاج اشتراك في Claude بيدعم Claude Code.
- **صوتك:** بتسجّله بنفسك، أو بتولّده من Google AI Studio (فيه نسخة مجانية).

## التسطيب من الموبايل (Claude Code على الموبايل أو الويب)
على الموبايل، Claude Code شغال على كمبيوتر في السحابة جاهز بكل البرامج، فمش محتاج تسطّب حاجة.
1. اعمل حساب على GitHub (مجاني)، واعمل repository فاضي (مثلاً `my-videos`).
2. من تطبيق Claude افتح **Code**، واربط GitHub، وابدأ جلسة على الـrepository ده.
3. ارفع ملف الحزمة (ZIP) في الشات واكتب:
   ```
   فك الحزمة دي، وحط فولدري eh-elhekaya-script و eh-elhekaya-animation جوه .claude/skills، واعمل commit و push
   ```
4. ابدأ **جلسة جديدة** على نفس الـrepository، عشان المهارات تتحمّل.
5. من هنا ورايح كل حاجة بالكلام، والصوت بترفعه كملفات في الشات، والفيديو بيتبعتلك تحمّله.

لو التطبيق مارضيش يرفع الـZIP، ارفع الفولدرين من كمبيوتر مرة واحدة على GitHub في `.claude/skills/`، وكمّل من الموبايل عادي.

## التسطيب على الكمبيوتر
1. فك ضغط الملف.
2. انسخ مجلدي `eh-elhekaya-script` و`eh-elhekaya-animation` لـ `~/.claude/skills/`.
3. افتح Claude Code واكتب:
   ```
   جهّز مهارة eh-elhekaya-animation
   ```
   Claude هيتأكد إن البرامج المطلوبة موجودة (Node.js وPython وffmpeg)، ويسطّب الباقي معاك خطوة بخطوة.

## الخطوات
1. **السكريبت:** «اكتب فيديو شرح عن [الموضوع]».
2. **راجع الحقايق** اللي في السكريبت بنفسك.
3. **سجّل الصوت:** ملف لكل سطر (`01`، `02`...)، أو ملف واحد بسكتة صغيرة بين كل جملة والتانية. على الموبايل ارفع الملفات في الشات، وعلى الكمبيوتر حطها في فولدر `voice/`.
4. **الرسم:** «ارسم الفيديو». Claude بيرسم المشاهد، ويوريك صورة فيها لقطة من كل مشهد، وتقدر تطلب تعديلات.
5. **الإخراج:** «طلّع الفيديو». بياخد حوالي 5 دقايق على الموبايل، و5 لـ15 دقيقة على الكمبيوتر.
6. **العناوين والـCover:** من المهارة الأولى أو `prompts/04-titles-cover.md`.

## لو مش معاك Claude Code
تقدر تستخدم البرومبتات في `prompts/` مع أي AI، عشان تكتب السكريبت والـstoryboard، وترسم بأي أداة زي Canva أو CapCut. بس الرسم الأوتوماتيك محتاج Claude Code (على الموبايل أو الكمبيوتر).

## ملاحظات
- الحقايق اللي في السكريبت لازم تتأكد منها بنفسك قبل النشر.
- الرسم بيطلع بأسلوب كرتوني ثابت، وجودته بتعتمد على وصفك للمشاهد وطلبات التعديل اللي بتطلبها.
- ماتنسخش تصاميم أو مشاهد من فيديوهات تانية. المحتوى لازم يكون من عندك.
