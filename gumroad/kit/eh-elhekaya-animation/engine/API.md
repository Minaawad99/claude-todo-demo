# مكتبة الرسم: المرجع الكامل

كل دالة بترجع **نص SVG**، وبتجمعهم بـ`+`. اللوحة (المشهد) مقاسها **640×360**: x من 0 (شمال) لـ640 (يمين)، وy من 0 (فوق) لـ360 (تحت). الخلفيات أعرض من اللوحة عشان الكاميرا تتحرك براحتها.

الملف ده للي هيكتب `shots.js` (Claude أو إنت). كل الدوال متاحة مباشرة في `shots.js` من غير import.

## شكل `shots.js`

```js
// مشهد لكل سطر من script.txt (السطور بتبدأ من 0)
shot(0, camPush(320, 180, 1, 1.1), function (u, d, t) {
  return sky("day") + clouds(t, 20, 30, 4, 0.9) + grass(t, 270)
       + person(320, 300, t, { mood: "curious", pose: "think" })
       + tag("ليه أزرق؟", 320, 80, u, 0.6);
});
```

- `shot(line, cam, draw)`: المشهد بيبدأ مع السطر `line` ويفضل لحد السطر اللي بعده.
- `draw(u, d, t)`: بترجع رسم المشهد.
  - `u`: الثواني من أول المشهد (للحاجات اللي بتظهر في وقت معين).
  - `d`: طول المشهد بالثواني.
  - `t`: الوقت من أول الفيديو (للحركة المستمرة: سحاب، عربيات، رمش العين...).
- `cam(u, d)`: بترجع `[x, y, zoom]`: النقطة اللي الكاميرا باصة عليها والزووم. المحرك بيضيف حركة خفيفة مستمرة فوقها، فالمشهد عمره ما بيقف.

### كاميرات جاهزة
| الدالة | بتعمل إيه |
|---|---|
| `camPush(x, y, z0, z1)` | زووم بطيء من `z0` لـ`z1` على النقطة (x, y) |
| `camPan(x0, x1, y, z)` | حركة جنب من `x0` لـ`x1` |
| `camMove([x,y,z], [x,y,z])` | من مكان وزووم لمكان وزووم تاني |

أو اكتب كاميرا بنفسك: `function (u, d) { return [320, 180, 1 + 0.1 * u / d]; }`

## أدوات
| الدالة | الوصف |
|---|---|
| `clamp(x)` | يحصر الرقم بين 0 و1 |
| `ease(x)` | حركة ناعمة من 0 لـ1 |
| `lerp(a, b, k)` | قيمة بين a وb |
| `pop(u)` | نطّة ظهور (0 → 1.15 → 1) |
| `hash(i)` | رقم عشوائي ثابت بين 0 و1 |
| `f(n)` | يقرّب الرقم لرقم عشري واحد (استخدمه جوه نص SVG) |
| `L(i)` | بداية السطر i بالثواني |
| `INK` | لون الخط الأسود `#1c1c1c` |

## خلفيات
| الدالة | الوصف |
|---|---|
| `fill(col)` | خلفية بلون واحد |
| `sky(kind)` | سما: `"day"` / `"dusk"` (غروب) / `"night"` / `"dawn"` |
| `sun(x, y, r, col)` | شمس بتوهج |
| `moon(x, y)` | هلال |
| `clouds(t, speed, y, n, opacity, scale)` | سحاب ماشي |
| `stars(t)` | نجوم بتلمع |
| `birds(t, y, speed)` | طيور طايرة |
| `city(t, y, h, col, winCol, seed, night)` | صف مباني (رجليها عند y) وشبابيك بتنور |
| `grass(t, y, kind)` | أرض عشب بيتمايل من y لتحت |
| `road(t, y, speed)` | شارع بخطوط وعربيات ماشية |
| `cars(t, y, speed)` / `car(x, y, col, scale)` | عربيات |
| `room(t, wallCol, floorCol)` | أوضة بحيطة وأرضية وشباك |
| `sea(t, y)` | بحر بموج من y لتحت |

## شخصيات
| الدالة | الوصف |
|---|---|
| `person(x, y, t, o)` | شخص رجليه عند (x, y). `o`: `mood`، `pose`، `s` (الحجم، 1 = حوالي 130 وحدة طول)، `shirt` (لون)، `look` (-1..1)، `hat` (`"hard"` خوذة / `"cap"` كاب) |
| `head(x, y, r, mood, t, look)` | راس بس |
| `bubble(x, y, text, u, u0, size)` | فقاعة كلام بتظهر عند u0 |

- **mood:** `"n"` عادي، `"happy"`، `"shock"` مصدوم، `"dizzy"` دايخ، `"curious"` مستغرب، `"worry"` قلقان.
- **pose:** `"stand"`، `"point"` بيشاور، `"wave"` بيسلّم، `"think"` بيفكر، `"cheer"` فرحان وإيده لفوق.

## علامات الشرح
| الدالة | الوصف |
|---|---|
| `tag(text, x, y, u, u0, rot, size, col)` | عنوان بفرشاة بيظهر بنطّة عند الثانية u0. `size` افتراضي 23، `col` لون الفرشاة |
| `label(text, x, y, size, col, weight)` | كلام عادي |
| `arrow(x1, y1, x2, y2, col, w, p)` | سهم بيترسم لحد `p` (0..1). مثال: `p = ease(u / 1.5)` |
| `pulse(x, y, t, col, r)` | دواير بتنبض |
| `sparkle(x, y, t, col, n)` | لمعة نجوم |
| `qmark(x, y, t, size, col)` | علامة استفهام كبيرة بتتمايل |
| `counter(x, y, u, u0, dur, from, to, suffix, size, col)` | رقم بيعد |
| `bar(x, y, w, h, p, col, back)` | شريط بيتملي لحد p |
| `check(x, y, u, u0, s)` / `cross(...)` | علامة صح / غلط بتظهر عند u0 |

## ألوان وتدرجات جاهزة
`url(#sky-day)` `url(#sea)` `url(#gMetal)` `url(#gGlass)` `url(#gGold)` `url(#screen)` `url(#road)`، وفلاتر: `url(#soft)` (ضباب)، `url(#soft2)`، `url(#glow)`.

لو محتاج تدرج جديد، اكتبه في ملف `defs.svg` في فولدر الفيديو (مثال: `<linearGradient id="myRed">...</linearGradient>`)، وهيتضاف لوحده.

## أشكال جديدة
لو الموضوع محتاج حاجة مش موجودة (طيارة، قلب، عربية مترو...)، اكتب دالة في أول `shots.js`:

```js
function rocket(x, y, t, s) {
  var flame = 10 + Math.sin(t * 20) * 4;
  return '<g transform="translate(' + f(x) + ' ' + f(y) + ') scale(' + (s || 1) + ')">' +
    '<path d="M0 -60 C20 -40 20 20 14 40 H-14 C-20 20 -20 -40 0 -60 Z" fill="#e8e4da" stroke="' + INK + '" stroke-width="3"/>' +
    '<path d="M-10 40 L0 ' + f(40 + flame * 2) + ' L10 40 Z" fill="#f28c28"/></g>';
}
```

**قواعد الأشكال:**
- خط أسود (`INK`) حوالين الأشكال.
- تدرج لون عشان الشكل يبان مجسّم.
- حاجة بتتحرك بـ`t`.
- لو الشكل حاجة حقيقية، ارسمه قريب من شكله الحقيقي (الأجزاء والألوان).

## قواعد المشاهد
1. **مفيش مشهد واقف:** لازم يبقى فيه حاجة بتتحرك طول الوقت (سحاب، عربيات، موجة، نبض، شخص بيرمش).
2. **العناوين (`tag`) تظهر متأخرة شوية** (u0 من 0.4 لـ1.5) عشان تيجي مع الكلام.
3. **خلي المهم في النص:** بين x = 80 و560، وy = 50 و320. الأطراف ممكن تتقص مع الزووم.
4. **أول مشهد يفتح على حاجة المشاهد يعرفها**، وبعدين ادخل في الشرح.
5. **مشهد لكل سطر.** لو نسيت سطر، المشهد اللي قبله هيكمل عليه.
