# ستايل السكتش («الرسم الهندسي»): المرجع الكامل

**الشكل:** ورق كريمي بمربعات خفيفة، وكارت بإطار مزدوج. الرسم مسطّح بخطوط رفيعة وتظليل مايل، وأسماء الأجزاء بتظهر بخطوط إشارة. تحت الرسم سطرين ترجمة فيهم كلمة ملوّنة، **من غير وشوش كرتون ومن غير عناوين فرشاة**.

**اللوحة عمودية: 640 عرض × 800 طول.** x من 0 لـ640، وy من 0 (فوق) لـ800 (تحت). كل دالة بترجع نص SVG.

## ترتيب الفيديو
| السطر | اللي بيظهر |
|---|---|
| 0 (الـhook) | **كارت البداية:** التصنيف، والجملة الكبيرة (من `config.json`)، ورسمة "صورة" تحتهم بتعملها بـ`intro(...)` |
| من 1 لقبل الأخير | **مشهد `shot(...)` لكل سطر** |
| آخر سطر | **كارت الملخص:** السؤال، ورسمة بأرقام، ورقم كبير، و3 نقط (من `config.json`)، والرسمة بتعملها بـ`outro(...)` |

## `config.json` للسكتش
```json
{
  "style": "sketch",
  "brand": "اسم قناتك",
  "sketch": {
    "category": "الفيزيا اللي حوالينا",
    "hook": "ليه السما لونها *أزرق*؟ | مع إن نور الشمس أبيض!",
    "outro": {
      "q": "السؤال كعنوان",
      "legend": ["جزء 1", "جزء 2", "جزء 3"],
      "stat": "≈5×",
      "statText": "شرح الرقم الكبير",
      "points": ["نقطة 1", "نقطة 2", "نقطة 3"],
      "more": "معلومة زيادة صغيرة"
    }
  },
  "keywords": { "6": {"قصيرة،": "b"}, "13": {"الغروب؟": "o"} }
}
```
- في `hook`: الكلمة بين `*نجمتين*` بتتلوّن برتقالي، واللي بعد `|` بيبقى سطر رمادي.
- **ألوان كلمات الترجمة:** `"o"` برتقالي (فعل أو خطر)، `"b"` أزرق (مصطلح علمي)، `"g"` زيتوني (اسم جزء). كلمة أو اتنين في السطر، ومكتوبة زي ما هي في السكريبت بالظبط.

## `shots.js`
```js
intro(function (t) {             // كارت البداية: رسمة 580×320
  return dark() + ring(290, 160, 70, t, ease(t / 1.2));
});
shot(1, camPush(320, 400, 1, 1.1), function (u, d, t) {
  return paper() + gearS(320, 380, 110, t, 0.6)
       + label(320, 270, 470, 170, "اسم الجزء", OLIVE, ease((u - 0.5) / 0.8));
});
outro(function (u, t) {          // كارت الملخص: رسمة 580×300، وu = الثواني من أول الكارت
  return '<rect width="580" height="300" fill="' + PAPER + '"/>' + callout("1", 100, 150, u / 0.6);
});
```
- **الكاميرات:** `camPush(x, y, z0, z1)`، و`camPan(x0, x1, y, z)`، و`camMove([x,y,z], [x,y,z])`. النص هو (320, 400).
- **u** = الثواني من أول المشهد، **d** = طول المشهد، **t** = الوقت من أول الفيديو.

## الألوان
`INK` حبر، `PAPER` ورق، `ORANGE` برتقالي، `BLUE` أزرق، `OLIVE` زيتوني، `PUTTY` رمادي فاتح، `SKIN` جلد، `BONE` أبيض عضم، `GREY` رمادي.
وفيه نقوش جاهزة: `url(#hatch)` تظليل مايل، `url(#hatchW)` تظليل أبيض (على الغامق)، `url(#grid)`، `url(#glass)`، `url(#glowO)` توهج برتقالي، `url(#glowW)` توهج أبيض.

## الدوال
| الدالة | الوصف |
|---|---|
| `paper()` | خلفية الورق بالمربعات |
| `dark(col)` | لوحة غامقة (للصور، والأشعة، والفضا، والتاريخ) |
| `R(x, y, w, h, fill, sw, rx)` | مستطيل بخط |
| `shape(d, fill, hatched, sw)` | أي شكل (مسار SVG) بلون، و`hatched = true` بيضيف تظليل |
| `circle(x, y, r, fill, hatched, sw)` | دايرة |
| `T(text, x, y, size, col, weight, anchor)` | كلام |
| `label(px, py, lx, ly, text, col, k, size)` | **اسم جزء بخط إشارة:** نقطة على الجزء وخط للكلام، و`k = ease((u - 0.5) / 0.8)` بيرسمه |
| `callout(n, x, y, k)` | دايرة برقم ① ② ③ |
| `crossMark(x, y, s, k)` | ✗ برتقالي كبير لفكرة غلط |
| `ring(x, y, r, t, k)` | دايرة حمرا بتترسم حوالين حاجة |
| `numBox(text, x, y, k, size)` | رقم في بوكس غامق ("100,000 V") |
| `waveRay(x1, y1, x2, y2, t, col, amp, wavelength, p, sw)` | موجة/شعاع متموّج |
| `arrow(x1, y1, x2, y2, col, w, p)` | سهم |
| `arrows(t, x1, y1, x2, y2, n, col, spread)` | حزمة أسهم ماشية (طاقة، هوا، حرارة) |
| `dots(t, x, y, w, h, n, col, speed)` | جزيئات بتتحرك |
| `inset(cx, cy, r, inner, k)` | دايرة تكبير لتفصيلة (`inner` مرسوم حوالين 0,0) |
| `figure(x, y, s, t, col)` | شخص بسيط من غير وش |
| `lamp(x, y, t, on, s)` | لمبة |
| `gearS(x, y, r, t, speed, col, teeth)` | ترس بيلف |
| `sunS(x, y, r, t)` | شمس |
| `globe(x, y, r, t)` | الكرة الأرضية بتلف |

## قواعد الستايل
1. **اللون المسطّح والخط الرفيع والتظليل** في الأشكال الكبيرة. مفيش وشوش كرتون ولا عناوين بفرشاة.
2. **كل جزء بيتقال اسمه في الكلام، اعمله `label`** في نفس اللحظة.
3. **ابدأ بتشبيه من الحياة،** وبعدين الجهاز الحقيقي في قطاع (من جوه)، وبعدين كبّر على كل جزء.
4. **فكرة غلط شائعة:** `crossMark` عليها، وبعدين الصورة الصح.
5. **مفيش مشهد واقف:** لازم حاجة بتتحرك (موجة، جزيئات، ترس، كاميرا).
6. **خلي المهم في النص:** بين x = 60 و580، وy = 80 و720.
