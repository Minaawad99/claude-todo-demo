# برومبت 2: الـStoryboard

بعد ما تخلص السكريبت، انسخ ده:

```
خد السكريبت اللي فوق واعمل منه storyboard جدول markdown لكل سطر، بالأعمدة:
| السطر | المشهد | الكاميرا | الكلمات المفتاحية (أصفر) | المؤثر الصوتي |

- المشهد: الشخصيات والمكان، وإيه الحاجة اللي بتتحرك طول الوقت (عربيات، أمواج، أضواء بتومض، دوائر بتنبض). ممنوع مشهد واقف.
- الكاميرا: ثابتة، أو بتقرب، أو بتبعد، أو بتتحرك جنب.
- الكلمات المفتاحية: 1 أو 2 كلمة من السطر تتلوّن أصفر.
- المؤثر الصوتي: whoosh قبل كل سطر، وبعدين مؤثر حسب الحركة (pop، ding، tick، splash...).
- أول مشهد يفتح على حاجة المشاهد بيشوفها كل يوم، وبعدين الكاميرا تسحب للشرح.
```
