# مكتبة المرجع: 20 فيديو «طب إزاي؟»

> **In this skill package:** the contact sheets are in `assets/reference/sheets/`, the motion strips in `assets/reference/frames/`, and the transcripts in `assets/reference/transcripts.txt`. The small videos are the separate `sketch-reference-videos.zip`. After `scripts/setup_workspace.sh`, all of them sit in `videos/_reference/tabizzay/` with the names used below.

دي الفيديوهات اللي أسلوب **«اسكتش»** اتبنى عليها. موجودة هنا عشان أي سيشن جديدة تستمد منها الرسم والأسلوب، من غير ما الفيديوهات
تترفع تاني. هي مرجع للنظر بس: بنرسم بنفس الإيد، لكن مش بننسخ رسمة ولا سكريبت.

| الملف | فيه إيه |
|---|---|
| `STYLE.md` | الدليل الكامل بالأرقام: السرد، والكادر، والألوان، والخطوط، والحركة، والصوت |
| `sheets/vNN.jpg` | لقطة كل 2.5 ثانية من الكارت، بعرض 300 بكسل. **أسرع حاجة تفتحها** عشان تشوف إزاي حاجة اترسمت |
| `videos/vNN.mp4` | الفيديو نفسه بحجم صغير (360 عرض، 15 فريم، بالصوت). منه تطلّع أي فريم أو لقطات متتالية للحركة |
| `frames/` | لقطات متتالية جاهزة للحركة: الافتتاحية، والفاصل، والانتقالات، وكارت الملخص |
| `transcripts.txt` | كلام الـ 20 فيديو بتوقيته |

**تطلّع فريم أو حركة:**

```bash
ffmpeg -ss 12.5 -i videos/v08.mp4 -frames:v 1 out.png                                        # فريم واحد
ffmpeg -ss 40 -t 2.4 -i videos/v08.mp4 -vf "fps=5,tile=6x2" -frames:v 1 strip.png             # حركة: 12 لقطة في 2.4 ثانية
```
