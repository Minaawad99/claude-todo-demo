# VideoCard

كارت حلقة في مكتبة الفيديوهات. لما تعدّي عليه بالماوس أو توصله بالكيبورد، جسم الجهاز بيبهت واللي جواه بيبان.

**إنت بتجهّز:** `a.tz-card` وجواه `.tz-card__thumb.tz-paper` (فيه SVG بـ viewBox 180×320 جواه مجموعتين: `g.tz-card__inner` للمقطع و`g.tz-card__shell` للجهاز من برّه، والـ inner الأول)، و`.tz-card__play` و`.tz-card__dur`، وبعدهم `.tz-card__meta` (فيه `tz-tag` و`.tz-card__time`)، و`h3.tz-card__title > span`.

- العنوان هو سؤال الحلقة زي ما هو.
- المدة بصيغة `m:ss`.
- الكروت بتتحط في grid بـ `minmax(180px, 1fr)` وبينهم 24px.
- ✗ متحطش صورة فوتوغرافية. الكارت دايمًا رسمة بنفس الستايل.
