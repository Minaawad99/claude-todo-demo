# Inset

دايرة تكبير بتوري حاجة صغيرة مش هتشوفها بعينك (إنزيمات بتقطّع الأكل، بقعة شاي).

**إنت بتجهّز:** `div.tz-inset` جوه الـ stage، مع `--x` و`--y` و`--size` (عرضها كنسبة من الـ stage)، وجواه SVG بـ viewBox 100×100.

- الحركة `data-tz="pop"`. ولو فيه حاجة بتتحرك جوه الدايرة، حط عليها حركة تفضل شغالة (`tz-spin` مثلًا).
- دايرة واحدة بس في المشهد، وفي الركن اللي فوق.
