# Callout

تسمية لجزء من الرسمة: نقطة على الجزء، وخط رفيع، وفي آخره التسمية.

**إنت بتجهّز:** `span.tz-callout` جوه عنصر `position: relative`، مع `--x` و`--y` (مكان النقطة بالنسبة المئوية)، و`--angle` (اتجاه الخط)، و`--len` (طوله)، و`--chip-shift` (مكان التسمية بالنسبة لآخر الخط، والافتراضي `-100% -50%`). وجواه بالترتيب: `__line` و`__dot` و`__chip`.

- لوّن التسمية بالمعنى: `tz-callout--heat` أو `--water` أو `--part`.
- الحركة `data-tz="callout"`: النقطة، بعدها الخط، بعدها التسمية.
- ✗ متحطش أكتر من 3 تسميات في المشهد. التسمية كلمة أو اتنين.
