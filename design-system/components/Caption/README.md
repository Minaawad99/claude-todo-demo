# Caption

سطر كابشن تحت الرسمة. الكلمة المهمة فيه بتاخد لون معناها، والفكرة الأساسية بيترسم تحتها خط.

**إنت بتجهّز:** `p.tz-caption`، وجواه الكلمة المهمة في `span.tz-k` مع نوعها: `tz-k--heat` أو `tz-k--water` أو `tz-k--part`، وأي فكرة أساسية في `span.tz-em`.

- الحركة: `data-tz="type"` للسطر (كلمة كلمة) أو `data-tz="ink"` (السطر كله مرة واحدة). وضيف `data-tz="key"` على الكلمة المهمة عشان لونها يظهر بعد ما السطر يخلص.
- الحجم 24px في الفيديو. في الكروت الأصغر غيّر `--tz-caption-size`.
- ✓ «وتحت فيه **سخان**...» ✗ متلوّنش أكتر من كلمة واحدة في السطر.
