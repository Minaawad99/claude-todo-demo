# Legend

أرقام مدوّرة على رسمة الملخص، وقايمة بأسماء الأجزاء دي.

**إنت بتجهّز:** `span.tz-num` فوق الرسمة (بـ position absolute)، و`ol.tz-legend` وكل `li` فيه `span.tz-num` والاسم. وعدد الأعمدة بيتغير بـ `--cols` (والافتراضي 2).

- الأرقام بترتيب الشرح في الحلقة، مش بمكانها في الرسمة.
- الحركة `pop` على كل رقم في الرسمة، وبعدها `fade` للقايمة.
