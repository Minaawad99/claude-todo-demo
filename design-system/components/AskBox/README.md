# AskBox

دعوة في آخر الحلقة: «قولولنا... عايزين تعرفوا طب إزاي ___؟». المشاهدين بيقترحوا السؤال الجاي.

**إنت بتجهّز:** `div.tz-ask` وجواه `span.tz-ask__lead` (سطر أو اتنين) و`span.tz-ask__line` وفيه `span.tz-ask__blank`. وفي الموقع، حط `input.tz-ask__blank` جوه `label.tz-ask__line` ومعاه زرار إرسال.

- المؤشر اللي بيرمش جوه الفراغ بيقف لوحده مع `prefers-reduced-motion`.
- الفورم بتتعامل مع الإرسال بنفسها (`preventDefault`، وبعدين تبعت لسيرفرك).
