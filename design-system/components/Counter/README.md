# Counter

الرقم اللي الحلقة كلها بتتكلم عنه. بيعدّ لحد قيمته ولونه على حسب معناه.

**إنت بتجهّز:** `div.tz-counter` وجواه `span.tz-counter__num` (والقيمة النهائية مكتوبة جواه، ومع `data-to`)، و`span.tz-counter__unit` (الوحدة وجملة المقارنة).

- الافتراضي `heat`. استخدم `tz-counter--water` لو الرقم كمية مية.
- الحجم بيتغير بـ `--num-size`: ‏96px للرقم الأساسي و40px للقراءات اللي جوه المشهد.
- الحركة `data-tz="count"`: بتبدأ من `data-from` (والافتراضي 0)، بتبدأ سريعة وتهدى في الآخر. والكسور بتتحسب من عدد الخانات العشرية اللي في `data-to`.
